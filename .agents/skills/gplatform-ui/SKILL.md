# GPlatform UI 开发

以当前生产界面为起点。路径除 `HOST_ROOT` 标记外均相对 `APP_ROOT`；完整宿主和独立 App 的定义见 `AGENTS.md`。

## 先查现有实现，再选择复用方式

1. **看实际页面**：明确用户要改变的行为与范围，找到真实加载入口和最接近的生产页面，核对其容器、布局、状态来源及打开/关闭流程。打印工作区从 `qml/pages/3DPrintPage.qml` 的 prepare/preview/realistic、路由与 Dock 状态入手。
2. **查应用组件和 SmoothUI**：先看 `qml/components/`、`qml/dialogs/`、相应 workspace 的已有封装，再查当前 SmoothUI/SmoothUIDock 组件、基类、属性、信号和用法。不能根据截图、其他 FluentUI fork 或过时文档猜接口。
3. **选择现成能力**：优先直接使用已有应用组件或库控件，通过现有属性、内容槽和信号组合需求。现有能力不足时先明确缺口，再决定局部组合、必要扩展或新增组件。
4. **沿用主题和交互**：复用颜色、Typography、尺寸、圆角、图标、动画及相同场景的焦点、键盘、鼠标、滚动和弹层行为。借鉴生产用法时核对其合理性，不复制已知缺陷。
5. **做最小完整接线**：区分界面局部状态、Bridge 投影与业务状态，沿现有接口实施并验证。纯布局修改留在 QML；业务修改沿已有 Handler、服务或 Action 进入，不为统一形式改写现有正常接线。

只查任务相关页面和候选组件，不要求每次扫描整个 UI 库。已有小修改直接实施，不引入通用设计问卷或额外审批。

## 按任务读取

- 组件、主题、Popup、Dock 与布局：[界面与组件](references/components-and-layout.md)。
- Bridge、业务状态、异步交互、国际化与验证：[接线与验证](references/state-and-validation.md)。

新页面先明确主要任务、内容层级、布局约束和交互状态。具体复用候选与新增组件判断见“界面与组件”，读取与当前任务相关部分即可。

## 控制新增实现与改动范围

- 已有控件能够满足需求时，直接复用；不再用 Rectangle/MouseArea/Text 重写按钮、输入框、滚动条或弹窗的整套交互。普通装饰和布局容器仍按需要使用基础元素。
- 先用已有属性、内容槽、信号和组合方式；不要整份复制组件后只改颜色/尺寸，也不要为一个页面增加通用控件框架、主题单例、弹窗管理器或事件总线。
- 新组件应有明确的现有能力缺口或实际复用价值，边界和 API 只覆盖当前需要；一次性的简单组合可以留在页面内，不为假设中的未来需求提前抽象。
- 状态、校验和派生值优先使用已有来源与绑定；新增缓存、镜像状态、轮询或强制刷新必须有具体必要性，不能掩盖通知或生命周期问题。
- 复用当前主题与工作区样式，不建立平行 token 或为局部页面重做全局风格。确需公共组件修改时，检查直接受影响的其他调用者。
- 每处修改都应能对应本次目标；不顺手重排无关页面、统一 imports、修改无关控件默认值或重写正常业务接线。UI bug 同时应用 `gplatform-bugfix`。

## 实施边界

- 核对实际组件 API 和 token，复用 `AppPopup`、`AppSurface`、`PrintWorkspaceStyle` 及现有页面模式。新增组件或 token 应有具体复用或语义需要。
- 保留主题切换、键盘焦点、Esc、外部点击、窗口缩放和页面切换行为；涉及任务时检查忙碌、取消、失败与重试。
- 可重复定位的交互控件使用清晰 `objectName`；不能为使测试通过增加绕过正常输入或业务流程的测试专用入口。
- 界面使用英文源文案与现有 gettext/Qt Bridge；参数 schema 文案走 `LibSlicerSettings` context。不要引入另一套 TS/QM 流程。
- 修改 QML 文件清单或单例时核对 `CMakeLists.txt` 的实际资源打包，不能只让编辑器预览成功。

## 验证与说明

选择能观察变化的检查：相关组件/Bridge 检查、真实应用布局与输入；要求真实操作验收时使用 `gplatform-journal`。只有完整宿主才使用其 `Core/tests`，独立 App 不要求不存在的测试。
完成前检查 diff：已有控件与交互是否得到复用，新增抽象/状态是否必要，是否存在重复绘制或业务规则，以及共享组件改动是否影响其他使用处。
说明改变的用户行为、复用入口、必要增量、接线位置和实际验证范围；截图支持外观检查，不能单独证明事务、切片或设备任务成功。
